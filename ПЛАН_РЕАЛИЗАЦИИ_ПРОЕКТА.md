#### 1.2. Прогнозная модель (Недели 1–4)

**Источники данных для прогноза:**
1. Открытые данные: OpenMeteo, Copernicus Atmosphere Monitoring Service (CAMS)
2. Данные с 4 собственных датчиков (газоанализаторы + пылемеры)
3. Данные Заказчика (загружаемые через email или API)
4. Данные аккредитованных лабораторий

**Алгоритм прогнозирования:**
```
Этап A — Базовый прогноз:
  - Метеорологическая модель WRF или ERA5 reanalysis
  - Химический транспортный расчёт (HYSPLIT или аналог)
  - Интерполяция на сетку города Кемерово

Этап B — Уточнение (data assimilation):
  - Поступают свежие измерения с датчиков
  - Калибровка модели по фактическим данным
  - Пересчёт прогноза с горизонтом 6+ часов

Этап C — Постобработка:
  - Расчёт AQI (российская методология)
  - Агрегация по 10+ контрольным точкам
  - Расчёт среднего по районам и по городу
  - Сохранение в БД временных рядов
```

**Периодичность запуска модели:** каждые 20 минут (обеспечивает требование 95% прогнозов с 20-минутным усреднением)

#### 1.3. Монтаж оборудования (до 31.08.2026)

**Шаги:**
1. Получение от Заказчика: схема монтажа + 4 адреса (День 1)
2. Выезд на обследование каждой точки (Дни 2–5)
3. Проверка соответствия мест требованиям ТЗ (высота, расстояния, связь, питание)
4. Согласование с Заказчиком и третьими лицами (неделя 1–2)
5. Монтаж оборудования (недели 2–4):
   - Газоанализаторы: комплект NO₂ + O₃ + CO + H₂S + SO₂ на каждую точку
   - Пылемеры PM2.5: 2+ канала, обогрев пробы
6. Подключение к GSM/Wi-Fi, настройка передачи данных на сервер
7. Верификация: проверка поступления данных в БД
8. Регистрация оборудования в ФГИС «Аршин» / проверка действующей поверки
