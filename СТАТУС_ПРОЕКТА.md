## Команды для запуска

```bash
# Клонировать репозиторий
git clone https://github.com/mintfary-oss/New-ismerenue.git
cd New-ismerenue/aqi-platform

# Запустить полный стек (требует Docker)
docker compose up -d

# Или установить одной командой
curl -fsSL https://raw.githubusercontent.com/mintfary-oss/New-ismerenue/main/aqi-platform/scripts/install.sh | bash
```
