## SPRINT 10 — ДЕТАЛИ

### 1. Grafana + Prometheus в Docker Compose

**Новые файлы:**
- `docker/prometheus/prometheus.yml` — scrape конфиг (`app:8080/metrics`, retention 90 дней)
- `docker/grafana/provisioning/datasources/prometheus.yml` — авто-подключение DS
- `docker/grafana/provisioning/dashboards/default.yml` — авто-загрузка дашбордов
- `docker/grafana/dashboards/aqi-platform.json` — готовый дашборд (12 панелей)

**Дашборд содержит:**
| Панель | Метрика |
|--------|---------|
| AQI Gauge (цвет по порогам) | `aqi_air_current_aqi` |
| История AQI (timeseries) | `aqi_air_current_aqi` |
| Активные соединения | `aqi_http_active_connections` |
| HTTP RPS по статусам | `rate(aqi_http_requests_total[1m])` |
| P95 latency | `histogram_quantile(0.95, ...)` |
| Датчиков активно / онлайн | `aqi_sensor_active_total/online_total` |
| Измерения по источнику | `rate(aqi_ingest_measurements_total[5m])` |
| IMAP проверки | `rate(aqi_imap_polls_total[5m])` |
| Время расчёта прогноза (P95) | `aqi_forecast_run_duration_seconds` |
| Go горутины | `go_goroutines` |
| Go heap memory | `go_memstats_heap_*` |

**Docker Compose:**
- Сервисы `prometheus` (prom/prometheus:v2.54.1) и `grafana` (grafana/grafana:11.2.0)
- Volumes `prometheus_data` (90 дней TSDB) и `grafana_data`
- Nginx проксирует `/grafana/` → grafana:3000 (с WebSocket)
- Grafana доступна по адресу `http://<host>/grafana/`
- `install.sh` генерирует и показывает `GRAFANA_PASSWORD`

### 2. AQI Алерты (email-уведомления)

**Новые файлы:**
- `internal/service/alert_service.go` — сервис проверки AQI порогов

**Архитектура:**
```
scheduler.runForecast()
    → alert.Check(ctx)           ← после каждого расчёта прогноза
        → measurements.Latest()  ← читает текущие значения
        → AQI >= threshold?      ← сравниваем с порогом
        → cooldown ok?           ← не отправляли 4ч?
        → RenderAQIAlertEmail()  ← HTML-шаблон с цветом категории
        → sender.SendAQIAlertHTML() ← SMTP отправка
```

**Конфигурация (env):**
| Переменная | По умолчанию | Описание |
|-----------|--------------|---------|
| `AQI_ALERT_ENABLED` | `false` | Включить алерты |
| `AQI_ALERT_THRESHOLD` | `101` | Порог AQI (Unhealthy for Sensitive) |
| `AQI_ALERT_COOLDOWN_DURATION` | `4h` | Кулдаун между алертами для одной точки |
| `AQI_EMAIL_SMTP_HOST` | — | SMTP-сервер |
| `AQI_EMAIL_SMTP_USER/PASS` | — | Логин/пароль |
