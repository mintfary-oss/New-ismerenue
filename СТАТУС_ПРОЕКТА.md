## SPRINT 9 — ДЕТАЛИ

### 1. Prometheus Metrics (`internal/metrics/metrics.go`)
- `/metrics` эндпоинт (Prometheus scrape endpoint)
- **HTTP middleware**: `aqi_http_requests_total`, `aqi_http_request_duration_seconds`, `aqi_http_active_connections`
- **Бизнес-метрики**: `aqi_air_current_aqi`, `aqi_ingest_measurements_total`, `aqi_forecast_runs_total`, `aqi_forecast_run_duration_seconds`, `aqi_forecast_errors_total`
- **Датчики**: `aqi_sensor_active_total`, `aqi_sensor_online_total`
- **IMAP**: `aqi_imap_polls_total`
- **DB пул**: `aqi_db_pool_total_conns`, `aqi_db_pool_idle_conns`
- Go runtime + process collectors (GC, goroutines, CPU)
- Graceful обработка дублирующихся коллекторов (тесты-friendly)

### 2. pg_dump Бэкап (`scripts/backup.sh`, `scripts/restore.sh`, `docker-compose.yml`)
- Автоматический pg_dump каждые **6 часов** (02:00 / 08:00 / 14:00 / 20:00)
- Хранение **30 дней** (настраивается `BACKUP_KEEP_DAYS`)
- Docker Compose сервис `backup` (postgres:17-alpine + Alpine crond)
- Volume `backup_data` для хранения дампов
- `restore.sh` — восстановление с явным подтверждением

### 3. E2E HTTP Тесты (`internal/e2e/e2e_test.go`)
- **15 тестов** через `net/http/httptest` — полный HTTP-стек
- In-memory мок всех репозиториев (без реальной БД)
- Покрытые сценарии:
  - `GET /health` → 200
  - `GET /ready` → 200 (nil пул)
  - `GET /metrics` → 200 Prometheus
  - `GET /api/v1/docs` → 200 Swagger UI HTML
  - `GET /api/v1/openapi.yaml` → 200 YAML
  - `GET /api/v1/public/forecast/points|current|city-average` → 200 (без токена)
  - `GET /widget/` и `/widget/data` → 200
  - 7 защищённых маршрутов без токена → **401**
  - `POST /api/v1/auth/login` (неверные creds) → **401**
  - `POST /api/v1/auth/login` (невалидный JSON) → **400**
  - Полный цикл login + ValidateAccessToken
  - Невалидный JWT → **401**
  - Несуществующий маршрут → **404**
