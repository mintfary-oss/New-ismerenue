## 1. ПРОЕКТЫ, ИЗУЧЕННЫЕ ПОЛНОСТЬЮ

### 1.1. Magistrala / Mainflux
**Репо:** https://github.com/absmach/magistrala  
**Язык:** Go | **Звёзды:** 2 600+ | **Лицензия:** Apache 2.0

**Что хорошего:**
- Чистая доменная архитектура (DDD)
- Полная поддержка MQTT, HTTP, WebSocket, CoAP
- mTLS аутентификация через X.509
- Развёртывание через Docker Compose
- Высокое тестовое покрытие

**Ошибки и проблемы, которые мы НЕ повторяем:**
- ❌ **23+ микросервисов** — невозможно запустить на слабом сервере без K8s
- ❌ Требует Kubernetes для продакшна — не self-hosted в реальном смысле
- ❌ Время первого запуска Docker Compose: 5–10 минут
- ❌ Минимальный RAM в Docker Compose: ~2–3 GB
- ❌ Нет встроенного web-UI — только CLI
- ❌ Сложная настройка для нетехнических пользователей
- ❌ Избыточен для задачи с 4 датчиками

**Наше решение:** Модульный монолит — 1 бинарник, 3 Docker-контейнера.

### 1.2. CasaOS (IceWhaleTech)
**Репо:** https://github.com/IceWhaleTech/CasaOS  
**Язык:** Go | **Звёзды:** 37 000+ | **Лицензия:** Apache 2.0

**Что хорошего:**
- **Установка одной командой:** `curl -fsSL https://get.casaos.io | bash`
- Go binary + SQLite → минимальная зависимость
- Поддержка amd64, arm64, armv7
- Чистая структура: `cmd/`, `api/`, `service/`, `model/`, `route/`
- OpenAPI (oapi-codegen) для генерации типов из spec
- Goreleaser для автоматических релизов

**Ошибки:**
- ❌ SQLite не подходит для временных рядов с высокой частотой записи
- ❌ Нет встроенной поддержки TimeSeries — используют SQLite
- ❌ Тесная связанность service-слоя и route-слоя

**Что берём:** Структуру проекта, подход к установке, OpenAPI-первый подход.

### 1.3. OpenAQ Platform
**Репо:** https://github.com/openaq  
**Язык:** Python + TypeScript | **Звёзды:** 90+ (суммарно)

**Что хорошего:**
- Хорошо документированный REST API
- Открытые данные о качестве воздуха со всего мира
- ETL пайплайны для разных источников данных

**Ошибки, которые мы НЕ повторяем:**

- ❌ Python → высокое потребление памяти (~150–300 МБ на процесс)
- ❌ Нет прогнозирования — только исторические данные
- ❌ Нет виджета для встраивания
- ❌ Нет поддержки физических датчиков

| Нет авто-установки | EnviroMonitor | install.sh + Docker Compose |
| Хардкод конфигов | многие | ENV + config.yaml + Viper |
| Нет миграций БД | многие | golang-migrate автоматически |
| Нет health-check API | многие | `/health` и `/ready` эндпоинты |
| Нет rate limiting | большинство | Middleware на Chi |
| bcrypt (устарел для 2026) | многие проекты | Argon2id (OWASP 2025) |
| JWT без ротации | многие | Access + Refresh tokens |
| GORM (медленный ORM) | многие Go-проекты | sqlc (compile-time SQL) |
| Нет сжатия ответов | большинство | gzip middleware |
| Нет CORS политики | многие | Strict CORS на Chi |
| Dockerfile без multi-stage | большинство | Multi-stage → ~12 МБ образ |
| Нет graceful shutdown | многие | signal.NotifyContext |

## 3. ВЫБОР ТЕХНОЛОГИЙ (С ОБОСНОВАНИЕМ)

### Go версия: 1.23+ (актуальная на 2026)
- `slog` для структурированного логирования (stdlib, Go 1.21+)
- `net/http` с улучшенным роутингом (Go 1.22+)
- `context.WithCancelCause` для отмены с причиной
- `slices`, `maps` из stdlib

### HTTP Router: Chi v5
**Почему не Gin:** Gin использует собственные типы Context, несовместимые со stdlib. Chi — 100% stdlib-совместим, используется в продакшне Cloudflare, Heroku, 99Designs.
**Почему не Fiber:** Fasthttp под капотом — несовместим с net/http middleware экосистемой.
**Почему Chi:**
```
- 22 600+ звёзд, активная поддержка 2026
- ~1000 LOC в ядре роутера
- Нет внешних зависимостей кроме stdlib
- Встроенные middleware: Logger, Recoverer, RealIP, RequestID, Compress
- Идиоматичный Go
```

### БД: PostgreSQL 17 + TimescaleDB 2.x
**Почему не InfluxDB:** Требует отдельной лицензии для кластеров; TimescaleDB — это PostgreSQL extension, одна БД для всего.
**Почему не ClickHouse:** Избыточна для объёмов 4 датчиков; нет хорошей поддержки транзакций.
**TimescaleDB hypertable для измерений:**
```sql
CREATE TABLE measurements (
    time        TIMESTAMPTZ NOT NULL,
    sensor_id   UUID        NOT NULL,
    no2         DOUBLE PRECISION,
    o3          DOUBLE PRECISION,
    co          DOUBLE PRECISION,
    h2s         DOUBLE PRECISION,
    so2         DOUBLE PRECISION,
    pm25        DOUBLE PRECISION,
    temperature DOUBLE PRECISION,
    humidity    DOUBLE PRECISION,
    pressure    DOUBLE PRECISION
);
SELECT create_hypertable('measurements', 'time');
```
Объём: 4 точки × каждые 20 мин × 60 мес = ~525 600 строк за 5 лет. Это ничто для TimescaleDB.

### SQL: sqlc (не GORM)
**Почему не GORM:**
- Reflection-based → медленнее в 3–5 раз на сложных запросах
- Скрывает SQL → трудно оптимизировать
- "Magic" поведение при eager loading

**sqlc преимущества:**
- Пишем чистый SQL → sqlc генерирует типобезопасный Go-код
- Compile-time проверка запросов
- Нет runtime reflection
- Читаемый сгенерированный код

### Аутентификация: JWT (golang-jwt/jwt v5) + Argon2id
**Почему Argon2id вместо bcrypt:**
- OWASP Password Storage Cheat Sheet 2025 рекомендует Argon2id первым
- Выигрывает оба типа атак: CPU и GPU brute force
- golang.org/x/crypto/argon2 — в стандартной библиотеке Go

**JWT схема:**
- Access Token: 15 минут (хранится в памяти браузера, не в localStorage)
- Refresh Token: 30 дней (httpOnly cookie, Secure, SameSite=Strict)
- Token rotation при каждом refresh
- Blacklist refresh-токенов в Redis при logout

### Карта: MapLibre GL JS v5
- **Лицензия:** BSD 2-Clause — абсолютно свободная, можно использовать коммерчески
- Fork от Mapbox GL JS после смены лицензии в 2020
- 11 300+ звёзд, активная разработка 2026
- WebGL-ускорение, поддержка WebGPU в разработке
- Российские тайлы: можно использовать OpenStreetMap, 2GIS tiles, или self-hosted

### Frontend виджет: Чистый TypeScript (без фреймворка)
**Почему не React:**
- React bundle для iframe: ~130–200 КБ gzip
- Чистый TS: ~15–30 КБ gzip
- iframe должен грузиться мгновенно
- Нет зависимостей = нет уязвимостей из npm

### Хранение конфигурации: Viper + ENV
```yaml
# config.yaml (опционально)
server:
  port: 8080
  tls: true

database:
  host: ${DB_HOST}
  port: 5432
```
Все секреты — только через ENV, никогда не в config.yaml.

## 4. БЕЗОПАСНОСТЬ: OWASP TOP 10:2025 РЕАЛИЗАЦИЯ

| OWASP | Уязвимость | Наша защита |
|-------|------------|------------|
| A01 | Broken Access Control | RBAC middleware (Admin/Analyst/Viewer), resource ownership check |
| A02 | Security Misconfiguration | Secure defaults, TLS, security headers, no debug в продакшне |
| A03 | Supply Chain Failures | go.sum lock, dependabot, minimal dependencies |
| A04 | Cryptographic Failures | TLS 1.3, Argon2id, AES-256-GCM для секретов в БД |
| A05 | Injection | sqlc parameterized queries, input validation на всех эндпоинтах |
| A06 | Insecure Design | Threat modeling, principle of least privilege |
| A07 | Authentication Failures | Argon2id, JWT rotation, rate limit на login, MFA-ready |
| A08 | Data Integrity Failures | Подпись API-токенов HMAC-SHA256, go.sum verification |
| A09 | Security Logging | Structured slog с correlation ID, audit log в БД |
| A10 | Mishandling Exceptions | Централизованный error handler, no stack traces в ответах |

**Заголовки безопасности (все включены по умолчанию):**
```
Content-Security-Policy: default-src 'self'
X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN (публичный виджет: ALLOWALL)
X-XSS-Protection: 1; mode=block
Strict-Transport-Security: max-age=31536000; includeSubDomains
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: geolocation=(), microphone=(), camera=()
```

├── Cache:      redis/go-redis v9
├── Testing:    testify + net/http/httptest

FRONTEND — Закрытая платформа
├── TypeScript 5.x (Vite build)

├── MapLibre GL JS 5.x (карта)
